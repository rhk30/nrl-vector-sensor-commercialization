Native RHKEARTH Experimental build. Maritime seeds worldwide AIS from the Open Waters global station catalog and station vessel snapshots before using bounded tiles for ongoing live refresh; vessel state is retained/deduplicated by MMSI. Submarine Cables use RHKEARTH-hosted OpenStreetMap ODbL snapshots when available, with browser Overpass only as fallback. Regional roadway CCTV uses current public Illinois IDOT/Travel Midwest and Illinois Tollway snapshot layers plus statewide INDOT TrafficWise cameras; generic webcams and YouTube feeds are excluded.
